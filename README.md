🎮 Rock Paper Scissors Game

A simple and interactive Rock, Paper, Scissors game built using HTML, CSS, and JavaScript. Challenge the computer, test your luck, and keep track of the score in this beginner-friendly web project.

🚀 Features
🎲 Random computer opponent
✊ Rock, 📄 Paper, ✂️ Scissors gameplay
📊 Live score tracking
🎨 Clean and responsive user interface
🖱️ Simple one-click controls
💻 Built with vanilla JavaScript (no frameworks)
🛠️ Technologies Used
HTML5
CSS3
JavaScript (ES6)
📷 How It Works
Click the Play button to start the game.
Choose Rock, Paper, or Scissors.
The computer randomly selects its move.
The winner is determined according to the classic game rules.
Scores are updated after every round.
🎯 Purpose

This project was created to practice fundamental JavaScript concepts, including:

DOM Manipulation
Event Handling
Functions
Arrays
Variables
Conditional Statements (if / else)
Random Number Generation
Basic Game Logic
